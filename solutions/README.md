# Solutions

Reference solutions for the exercises in this repository. Open a solution alongside its source notebook to check your work.

| File / Folder | Description |
|---|---|
| [**2 - Classification**](2_decision_trees_classification.ipynb) | Worked solution for the "Improve our model" exercise: a regularised, class-weighted Decision Tree tuned with RandomizedSearchCV on ROC-AUC, then re-evaluated against the baseline and the unconstrained tree with a confusion matrix and ROC curve. |
| [**3 - Recap**](3_decision_trees_recap.ipynb) | Worked answers to the eight recap questions in collapsible toggles, including the tree grown by hand on the sample data set with the Gini gain calculated at each split. |
| [**Recap Board**](decision_tree_recap.excalidraw) | The worked Excalidraw board for the pair exercise: the answered counterpart to the blank board in `assets/`, showing the tree grown step by step with the Gini calculations. |
